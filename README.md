# PyScheduler

An educational Autosys / Control-M style job scheduler, built from scratch
in Python on our own libraries: [pynet](https://github.com/robcox2910/pynet)
(event loop and processes), [pymq](https://github.com/robcox2910/pymq)
(message broker), [pyweb](https://github.com/robcox2910/pyweb) (web server)
and [pydb](https://github.com/robcox2910/pydb) (journalled database).

Work in progress -- see `docs/superpowers/specs/` for the design.
